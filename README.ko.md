# WRITEME

[English](https://github.com/dltldn333/WRITEME/blob/main/README.md)

모노레포의 모든 패키지 `README.md`를 공통 파츠 하나로 조립합니다.

## 왜 필요한가요

모노레포의 패키지 README에는 같은 섹션이 반복됩니다. 설치 방법, 문의처, 라이선스 같은 것들입니다. 복사본마다 손으로 고쳐야 하고, 시간이 지나면 내용이 서로 달라집니다.

WRITEME는 README를 직접 고치는 원본 파일과 자동으로 만들어지는 결과로 나눕니다.

| 파일 | 들어가는 내용 | 직접 수정 |
|---|---|---|
| **`BASE.md`** | 메인 파츠. 문의처, 라이선스처럼 모든 패키지가 함께 쓰는 글. `writeme init`이 만들고 등록합니다. | 합니다 |
| **추가 파츠** (`parts/*.md`) | 그 밖의 공통 섹션. 패키지 이름 같은 값을 받을 수 있습니다. | 합니다 |
| **`WRITEME.md`** | 그 패키지에만 있는 글, 그리고 파츠가 들어갈 자리에 `::이름` 한 줄. | 합니다 |
| **`README.md`** | 조립 결과. 빌드할 때마다 새로 써집니다. | 하지 않습니다 |

## 설치

```bash
npm i -D writeme-cli
```

또는

```bash
go install github.com/dltldn333/WRITEME/cmd/writeme@latest
```

## 따라 해보기

패키지 두 개가 있는 모노레포입니다. 두 패키지 모두 같은 문의처, 기여 안내, 라이선스 섹션으로 끝나고, 각자 자기 패키지 이름으로 설치 방법을 보여줍니다.

```text
my-monorepo/
├── writeme.yaml
├── BASE.md                 메인 파츠, 모든 패키지가 함께 씀
├── parts/
│   └── install.md          패키지 이름을 받는 추가 파츠
└── packages/
    ├── core/
    │   └── WRITEME.md      @acme/core 이야기만
    └── react/
        └── WRITEME.md      @acme/react 이야기만
```

### 1. 파츠 등록하기

`writeme init`을 실행하면 `BASE.md`가 이미 등록된 `writeme.yaml`이 만들어집니다. 그 아래에 파츠를 더 추가하면 됩니다. `parts`에 적은 파일은 파일 이름으로 부르는 컴포넌트가 됩니다. `BASE.md`는 `::BASE`, `parts/install.md`는 `::install`입니다.

```yaml
entry: WRITEME.md
parts:
  - BASE.md
  - parts/install.md
output: README.md
```

### 2. 공통 글은 한 번만 쓰기

`BASE.md`에는 모든 패키지 README 끝에 들어갈 글을 씁니다. 어디서나 똑같으니 받을 값이 없습니다.

```markdown
## Support

Found a bug or have a question? Open an issue at
https://github.com/acme/toolkit/issues and include the package name and version.

## Contributing

Read https://github.com/acme/toolkit/blob/main/CONTRIBUTING.md before opening a pull request.

## License

MIT © Acme
```

`parts/install.md`에는 패키지 이름이 필요합니다. 그래서 프론트매터에 `pkg`를 받는다고 선언하고, 본문에서 `{{ pkg }}`로 씁니다.

```markdown
---
props:
  - pkg
---

## Install

Install `{{ pkg }}` with the package manager you already use:

- npm: `npm install {{ pkg }}`
- pnpm: `pnpm add {{ pkg }}`
- yarn: `yarn add {{ pkg }}`

Node.js 18 or newer is required.
```

### 3. 패키지마다 다른 글만 쓰기

`packages/core/WRITEME.md`에는 `@acme/core`의 제목, 설명, 사용법만 씁니다. 설치 방법은 한 줄이고, 마지막은 `::BASE`로 끝납니다.

````markdown
# @acme/core

Small, dependency-free helpers for dates, strings, and retries.
Every other package in this repository is built on top of it.

::install{pkg="@acme/core"}

## Usage

```ts
import { retry } from "@acme/core";

const user = await retry(() => fetchUser(id), { attempts: 3 });
```

::BASE
````

`packages/react/WRITEME.md`는 같은 파츠에 `pkg` 값만 다르게 넘깁니다.

```markdown
# @acme/react

React hooks for the Acme toolkit.

::install{pkg="@acme/react"}

## Usage

Wrap your app in `<AcmeProvider>` and call `useAcme()` inside any component.

::BASE
```

### 4. 빌드하기

`writeme.yaml`이 있는 폴더에서 실행합니다.

```bash
npx writeme build
```

```text
Wrote packages/core/README.md
Wrote packages/react/README.md
```

### 5. 결과

`packages/core/README.md`:

````markdown
<!-- Generated by WRITEME. Do not edit this file; edit WRITEME.md instead. -->

# @acme/core

Small, dependency-free helpers for dates, strings, and retries.
Every other package in this repository is built on top of it.

## Install

Install `@acme/core` with the package manager you already use:

- npm: `npm install @acme/core`
- pnpm: `pnpm add @acme/core`
- yarn: `yarn add @acme/core`

Node.js 18 or newer is required.

## Usage

```ts
import { retry } from "@acme/core";

const user = await retry(() => fetchUser(id), { attempts: 3 });
```

## Support

Found a bug or have a question? Open an issue at
https://github.com/acme/toolkit/issues and include the package name and version.

## Contributing

Read https://github.com/acme/toolkit/blob/main/CONTRIBUTING.md before opening a pull request.

## License

MIT © Acme
````

`packages/react/README.md`에도 `@acme/react`로 채워진 Install 섹션과 `BASE.md`의 섹션들이 똑같이 들어갑니다. 모든 패키지의 문의처, 기여 안내, 라이선스 문구를 바꾸려면 `BASE.md` 하나만 고치고 다시 빌드하면 됩니다.

## 레퍼런스

### 명령어

| 명령어 | 하는 일 |
|---|---|
| `writeme init` | 현재 폴더에 `BASE.md`가 등록된 `writeme.yaml`과 `BASE.md`, `WRITEME.md`를 만듭니다. 이미 있는 `WRITEME.md`와 `BASE.md`는 그대로 둡니다. |
| `writeme build` | 현재 폴더 아래의 모든 `WRITEME.md`를 찾아 각 파일 옆에 `README.md`를 씁니다. `.git`, `node_modules`, `vendor`는 건너뜁니다. |
| `writeme help` | 명령어 도움말을 보여줍니다. |

### writeme.yaml

| 키 | 의미 |
|---|---|
| `entry` | 각 패키지에 있는 원본 파일 이름. `init`은 `WRITEME.md`로 씁니다 |
| `parts` | 공통 파츠 경로. `writeme.yaml` 위치 기준. `init`은 `BASE.md`로 씁니다 |
| `output` | 원본 옆에 만들 파일 이름. `init`은 `README.md`로 씁니다 |

### 파츠 규칙

- 한 줄에 `::이름`만 있으면 그 줄이 해당 파츠로 바뀝니다. 이름은 파일 이름에서 `.md`를 뺀 것이라 `BASE.md`는 `::BASE`입니다.
- 값은 `key="value"` 형태로 넘깁니다. 예: `::install{pkg="@acme/core"}`
- 파츠는 받을 값을 전부 프론트매터의 `props`에 선언해야 합니다.
- 파츠 안에서 다른 파츠를 부를 수 있습니다. 결국 자기 자신을 다시 부르게 되면 에러입니다.
- `{{ 이름 }}`은 일반 글과 한 줄 코드(`` `...` ``) 안에서 치환됩니다. ``` 코드 블록 안은 그대로 복사되니, 값이 필요한 명령어는 위 `parts/install.md`처럼 한 줄 코드로 쓰세요.
- 없는 파츠, 선언 안 된 값, 값이 없는 `{{ }}`를 만나면 파일과 줄 번호를 알려주고 빌드를 멈춥니다. 이때 `README.md`는 하나도 만들지 않습니다.
